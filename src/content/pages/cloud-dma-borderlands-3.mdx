## Single-PC Hyper-V Environment

One of the defining parts of the Cloud DMA configuration is its use of Hyper-V.

Hyper-V is Microsoft's virtualization technology, allowing a compatible Windows PC to create and manage virtual environments.

For this setup, CPU virtualization must be enabled in firmware, and the Windows installation must support the Hyper-V role.

Windows 10 and Windows 11 64-bit are listed as supported operating systems. Windows Pro, Enterprise and Education editions are recommended for the Hyper-V setup.

The system requirements also include:

- At least 8 GB of system RAM.
- 16 GB RAM recommended.
- Intel VT-x or AMD-V CPU virtualization.
- HVCI enabled.
- Core Isolation enabled.
- TPM enabled.
- Secure Boot enabled.
- Stable broadband internet.

## Cloud DMA System Requirements

Before starting the installation, check that your computer meets the requirements.

**Operating system:** Windows 10 or Windows 11, 64-bit.

**Processor:** A CPU with Intel VT-x or AMD-V virtualization support.

**Memory:** 8 GB RAM minimum, with 16 GB recommended.

**Virtualization:** Hyper-V role support and the ability to enable CPU virtualization in firmware.

**Windows security settings:** HVCI, Core Isolation, TPM and Secure Boot enabled.

**Connectivity:** Stable broadband internet for service activation and ongoing connectivity.

The complete Borderlands 3 configuration also uses Greenward, Static Server and AWS as additional required components. These are distinct components of the setup and are provisioned separately.
